# Interview-Preparation

## 📌 Project Overview

Interview-Preparation is a personalized interview preparation system designed to help students prepare for technical and HR interviews.

It provides interview questions, practice sessions, and useful preparation resources in one place.

## 🎯 Features

- Personalized interview preparation
- Technical interview questions
- HR interview questions
- Mock interview practice
- Resume-based preparation
- Interview performance analysis
- User-friendly interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Database

## 🚀 How to Run

1. Download or clone this repository.
2. Extract the project files if required.
3. Open the project in VS Code.
4. Install the required dependencies.
5. Run the application.
